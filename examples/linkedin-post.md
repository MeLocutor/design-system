# LinkedIn Post Template — Estrutura PESTA

> Referência para posts de LinkedIn seguindo a Voz de Marca. Usar com `post_cover` component (ilustração hero + título overlay).

---

## Estrutura PESTA (700–900 chars)

```
[P] Preliminar/Hook — 1 frase forte, tese ou pergunta
[E] Encenação — Contexto: briefing recebido (1-2 parágrafos curtos)
[S] Sistema — Reframing: pergunta feita + decisão tomada (1-2 parágrafos)
[T] Takeaway — Resultado com métrica + o que isso ensina (1 parágrafo)
[A] Abertura — Pergunta de engajamento (1 frase)
```

---

## Exemplo Pronto (Artefato de Prova - Gamificação)

> Recebi um briefing: "criar uma promoção."
>
> Antes de abrir o Figma, perguntei: como transformar uma ação pontual em um ciclo de engajamento recorrente?
>
> Propus uma mecânica de cartas colecionáveis. Cada aposta alimentava uma progressão. Desenhei o sistema, prototipei, documentei a decisão com rationale.
>
> Resultado: +1048% de engajamento (72 → 827). Stake médio: R$821 → R$6.790.
>
> O padrão não é sorte — é método: questionar o briefing antes de executar, documentar a decisão com rationale, medir antes e depois.
>
> Esse case veio do iGaming. As métricas medem retenção e adoção — o mesmo padrão que funciona em healthtech, fintech ou SaaS.
>
> Qual foi a última vez que questionar um briefing gerou um resultado que você não esperava?

## Checklist Pré-Publicação (Voz de Marca §3.6)

- [ ] **Zero adjetivos vazios**: apaixonado, transformador, disruptivo, inovador, segredo
- [ ] **Zero emojis** em conteúdo profissional
- [ ] **Dado antes de adjetivo**: baseline → resultado com números
- [ ] **Método antes do resultado**: briefing → pergunta → decisão → métrica
- [ ] **Parágrafos 1–3 linhas**, uma ideia por parágrafo
- [ ] **Primeira frase de cada parágrafo carrega a tese**
- [ ] **Setor nomeado + traduzido**: "iGaming → traduz para fintech/health"
- [ ] **Pergunta de engajamento real** no final (não "o que acham?")
- [ ] **Ícone de categoria** no topo (Iconografia §5): Pergunta-em-Caixa para reframing, Gráfico-Ascendente para métrica, etc.
- [ ] **Capa ilustração hero** (Ilustrações §6): tema mapeado por categoria, título Sentient overlay
- [ ] **Teste legibilidade 40px thumbnail** antes de publicar

## Formatos por Tipo de Conteúdo (Voz de Marca §2.2)

| Tipo | Tom | Abertura típica |
|------|-----|-----------------|
| **Artefato de Prova** (micro-case) | Direto + Didático | "Recebi um briefing pra X. Perguntei: como Y?" |
| **Tese / Ponto de vista** | Investigativo + Técnico | "Times de produto têm um problema que não é de ferramenta — é de decisão que morre no contexto." |
| **Estrutura / Método** | Didático + Enxuto | "Documentação como infraestrutura funciona em 3 camadas: contexto, decisão, rationale." |
| **Pessoal / Origem** | Autêntico + Enxuto | "Meu primeiro contato com sistemas não foi num curso — foi na locadora dos meus pais." |
| **Opinião / Filtro** | Direto + Investigativo | "Produtos que exploram vulnerabilidade cobram um preço que não aparece no salário." |
